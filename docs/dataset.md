# Datasets

This repository uses two YCB object sets shipped under `data/`:

| Directory           | Format    | Purpose |
| ------------------- | --------- | ------- |
| `data/raw/ycb/`     | OpenRAVE KinBody XML + mesh files (STL / DAE / OBJ / PLY) | Raw YCB object set as shipped. Not modified by the pipelines. |
| `data/processed/`   | MJCF wrappers + serialized `.npy` records                | Generated from the raw set by `scripts/prepare_ycb_mjcf.py` and `scripts/prepare_data.py`. Excluded from version control (see `.gitignore`). |

Both sets are regenerated by `scripts/run_artifacts.py`. For details on the
serialized-sample contract, see `src/grasping_ai/data/pointcloud_dataset.py`
and `docs/Phase 3 Data Pipeline & Perception.md`.
